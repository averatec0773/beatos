# NetEase Cloud Music platform adapter

NetEase is the source of BeatOS's seed vocab (74 genres, 50 moods). For now the genre/mood mappings are identity — BeatOS's English label is the same as NetEase's English label.

When publish-to-NetEase ships, this directory will gain:
- An auth/session module
- An upload client
- The genre/mood maps (which will only need entries for items NetEase renames)
